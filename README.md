# Nomad Enterprise Landing Page

A responsive, conversion-focused enterprise SaaS landing page concept for Nomad's transportation platform, bringing together fraud review, cross-carrier visibility, fuel spending, and factoring data.

Built as an independent web development skills assignment, with the business objective of increasing demo requests by 20%.

[View the live website](https://jocular-tanuki-a29322.netlify.app/)

## Project objective

Introduce Nomad's enterprise platform to CFOs, operations executives, and risk management leaders at mid-size and large transportation companies.

The landing page prioritizes clear business messaging, product visualization, credibility, and a streamlined demo request experience.

## Tech stack

- **HTML5** — Semantic page structure and form controls.
- **CSS3** — Responsive layouts, reusable styles, and design tokens.
- **Vanilla JavaScript** — Mobile navigation, form validation, and local analytics events.
- **SVG** — Icons, favicon, and dashboard visualizations.

## Key features

- Responsive desktop, tablet, and mobile layouts.
- Illustrative enterprise SaaS dashboard.
- Benefit-driven messaging covering all three core platform capabilities.
- Multiple strategically positioned demo CTAs.
- Client-side form validation and simulated submission.
- Analytics-ready conversion events.
- Accessibility and performance considerations.

## Run locally

Open `index.html` in a browser.

No dependencies, installation, server, or build process is required.

## Demo details and assumptions

The dashboard uses fictional sample data for illustrative purposes.

The demo form validates entries in the browser and simulates submission without transmitting or retaining personal information.

Analytics events are demonstrated locally without connecting to an external analytics service.

The page includes a `noindex` directive because it is an independent hiring assignment rather than an official Nomad website.

## Deployment

The website is hosted on Netlify.

To update the deployment, upload the project folder through the Deploys tab of the existing Netlify project, ensuring `index.html` remains at the root.

## Disclaimer

This project is an independent skills assignment and is not an official Nomad product or production website.
