# Nomad Enterprise Landing Page

A responsive landing page concept for a fleet platform that brings together fraud review, cross-carrier activity, fuel spending, and invoice funding. Built as an independent web development assignment.

[View the live site](https://jocular-tanuki-a29322.netlify.app/)

## Tech stack

- **HTML** for page structure and form controls
- **CSS** for styling and responsive layouts
- **Vanilla JavaScript** for the mobile menu, form validation, and local analytics events
- **SVG** for icons, the favicon, and the dashboard chart

## Run locally

Open `index.html` in a browser. No server, installation, or build step is required.

## Demo details

The dashboard uses fictional sample data. The demo form validates entries in the browser and simulates submission without sending or retaining the information. The page includes `noindex` because it is an independent assignment.

## Deploy

Upload the project folder to the **Deploys** tab of the existing Netlify project. Keep `index.html` at the root of the folder.
